## 앵글
종이 대본 한 장이 영상의 주인공이다. 첫 장면에서 주인공이 줄을 놓치는 그 종이가 PDF로 접혀 프롬프터에 들어가고, 거기서부터 대본·연결·발표·일정이 한 화면 위에서 이어진다. 카메라는 큰 작업대(종이 → 노트북 → 발표장 → 시간표) 위를 끊김 없이 이동한다. 마지막에 일정 막대가 빠져나와 “예전 준비 vs 지금 준비” 시간표로 펼쳐진다.

## 숫자 맞추기
- 20장 · 18분(1,080초). 1번 장표 배정 50초(AI 결과 ‘=== 1 (50s) ===’).
- 음성 추적 장면: 이 장표 27초 경과 → 시간 54%(27/50), 읽음 57%, 차이 3%p → ‘● 적정 페이스’(앱 규칙: -12%p 초과 늦음, +15%p 이상 빠름). 이 속도면 27 ÷ 0.57 ≈ 47초 → ‘0:47 걸림 / 배정 0:50’. 총 경과 00:27 → 남은 시간 17:33.

## 사실 확인 (코드 대조, 작업 트리 기준)
- 화면 문구는 prompter.html·remote.html·deck.html·css/app.css(미커밋 ‘A안 · 방송 콘솔’ 디자인) 그대로.
- AI 대본 생성은 API 키나 팀 서버(팀 암호)가 있어야 동작 → 화면에 ‘API 키’ 칸을 가려 둔 상태로 보여 줌.
- 3자리 연결·폰 리모컨은 인터넷과 공개 PeerJS 서버가 필요(코드 그대로의 동작).
- 넣지 않은 것: 미러 모드·일정 속도 자동 스크롤(코드에 없음), 사용 건수(앱이 모름).
- 개인정보: 실제 이름·메일·주소 없음. 기기 연결 패널의 deck 주소는 ‘…/deck.html’로 줄여 표시.
