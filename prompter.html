🤖 방법 A — AI가 슬라이드를 직접 읽고 대본 작성Claude API 키 필요

PDF 각 페이지의 그림과 글자를 Claude에게 보여 주고, 총 발표 시간에 맞춘 페이지별 대본과 배정 시간을 받아 아래 칸에 채웁니다. 확인 후 ‘대본 적용’을 누르세요.

키 발급 ↗
키는 이 브라우저에만 저장되고, 슬라이드는 이 브라우저에서 Anthropic API로 바로 전송됩니다(이 앱은 서버가 없습니다). 요금은 키 주인의 계정에 청구됩니다.
방법 B — 쓰던 AI 채팅(ChatGPT·Claude 등)에 직접 붙여넣기
1
LLM 프롬프트를 복사한다

아래 버튼을 누르면 “페이지별 대본을 === 1 === 형식으로 써 달라”는 프롬프트가 복사됩니다.

2
LLM에 붙여넣고 원본 슬라이드를 함께 첨부한다

ChatGPT·Claude 등에 프롬프트를 붙여넣고, 발표 원본(PDF 또는 페이지 이미지)을 같이 첨부하세요. LLM이 슬라이드를 보고 페이지별 대본을 === 1 === 형식으로 작성해 줍니다.

3
받은 결과를 아래 칸에 붙여넣는다

LLM 출력 전체를 그대로 붙여넣으면 됩니다. 직접 작성도 가능 — 구분 === 1 ===(--- 페이지 2 ---, # 3 도 인식), 강조 **별표**, 시간 === 3 (60s) ===.

4
‘대본 적용’을 누른다

페이지별로 자동 편성·저장됩니다.

이 페이지에 영상 첨부
